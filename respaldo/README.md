# Respaldo de presentación

Estos archivos son el plan B para la presentación en vivo. No dependen de la red.

| Archivo | Qué es |
|---|---|
| `sitio-completo.pdf` | Anexo D3 completo: los cuatro productos, sus tablas de rubros, itinerarios resumidos, supuestos, fuentes y verificación. 15 páginas A4. |
| `turista.png` | Captura del nivel Turista (precio, ficha y hotel/vuelos). |
| `media.png` | Captura del nivel Clase media. |
| `alta.png` | Captura del nivel Clase alta. |
| `asia.png` | Captura del nivel Asian Tour. |
| `comparador.png` | Captura de la tabla comparativa. |
| `transparencia.png` | Captura de la sección de aritmética. |
| `asia-mapa.png` | Captura del mapa y la banda de precio del Asian Tour. |
| `portada.png` | Captura de la portada en 16:9. |
| `movil-portada.png` | Captura de la portada en celular (390 × 844). |

## Cómo usarlos

1. Si falla la red o GitHub Pages: abre `sitio-completo.pdf` y proyecta.
2. Si falla el PDF: muestra las capturas en orden `turista.png`, `media.png`, `alta.png`, `asia.png`.
3. Si falla la proyección: el equipo puede seguir con el guion; las capturas están en el celular.
4. Si el jurado pide una cifra: el PDF tiene la tabla de rubros y las fuentes.

## Nota

Las capturas se generaron desde el sitio local con Chrome headless a 1440 × 1100 (escritorio) y 390 × 844 (celular). El PDF se generó desde `anexo.html` con Chrome headless, tamaño A4, sin encabezados ni pies de página.
